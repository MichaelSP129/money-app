# Money (hosting copy)

This repository is only the **hosting copy** of the Money app, a free personal budget and spending app that works offline. It holds just the files GitHub Pages serves.

**Live app:** https://michaelsp129.github.io/money-app/

Development, tests, issues and pull requests are in a separate **private** repository. Please don't open issues or pull requests here. Changes are copied here from the private repo's `main` branch after they're merged.

## Privacy
Everything you enter stays on your own device (browser `localStorage`). Nothing is sent to a server, and this repo contains no personal or financial data: the app starts blank with generic categories.
